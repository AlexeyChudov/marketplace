# Деплой

Цель: получить публичный URL, открыть его в браузере и потыкать собственный API через фронт.

На оценку это не влияет, тесты этого не проверяют. Но сделать стоит: пока сервис живёт на `localhost`, ты не представляешь как он с фронтом интегрируется. А есть возможность посмотреть как работает твое поделие). Заодно вылезут ровно те грабли, которых не видно локально: порт из окружения, секреты в переменных, статика внутри бинаря.

---

## Как это устроено

Фронтенд (`web/index.html`) **вшит в бинарь** через `embed.FS` и отдаётся с `/`. Значит:

```
                    ┌─────────────────────────┐
  браузер ────────► │  один Go-бинарь         │
                    │  /        → index.html  │
                    │  /listings → JSON API   │
                    └─────────────────────────┘
```

Один артефакт, один сервис, один URL. Фронт по умолчанию бьётся в тот же origin, откуда его загрузили, — поэтому он просто работает.

### Про Docker

В репозитории лежит готовый `Dockerfile` — это рецепт, по которому платформа соберёт твой сервис у себя.

**Разбираться в нём не нужно.** Docker будет отдельной темой позже; сейчас он тут просто чтобы деплой заработал с первого раза. Ставить Docker себе на компьютер тоже не надо — сборка происходит на стороне Render. Файл лежит под `CODEOWNERS`, менять его не требуется.

Единственное, что от тебя нужно знать: платформа запустит твой бинарь **без флага `--addr`** и передаст порт через переменную `PORT`. Отсюда правило выбора адреса в README.

## Шаг 1. Проверь локально то, что поедет в облако

Сначала убедись, что твой сервис ведёт себя как контейнер, а не как «у меня на ноуте работает». Docker для этой проверки не нужен:

```bash
# Собираем и запускаем ровно так, как это сделает платформа:
# без --addr, порт из окружения.
go build -o /tmp/marketplace-api .
cd /tmp && JWT_SECRET=devsecret PORT=9999 ./marketplace-api
```

Обрати внимание на `cd /tmp`. Бинарь запускается из директории, где нет папки `web/`. Если он всё равно отдаёт страницу на <http://127.0.0.1:9999/> — `embed` работает. Если 500 или паника — ты читаешь файл с диска, и в контейнере это сломается точно так же. Тест `TestAcc16_ServesFrontend` проверяет ровно это.

Этих двух команд достаточно. Если всё отвечает — можно деплоить.

## Шаг 2. Render (рекомендуемый путь)

В репозитории уже лежит `render.yaml` — Render найдёт его сам и настроит сервис без единого поля в веб-интерфейсе.

1. Зайди на <https://render.com>, войди через GitHub.
2. **New +** → **Blueprint**.
3. Выбери свой репозиторий с этим заданием.
4. Render покажет, что нашёл сервис `marketplace-v2` из блюпринта. Жми **Apply**.
5. Ждёшь 3–5 минут первой сборки.
6. Получаешь URL вида `https://marketplace-v2-xxxx.onrender.com`. Открывай — увидишь свою консоль.

`JWT_SECRET` Render сгенерирует сам (`generateValue: true` в блюпринте). Секрет остаётся в настройках сервиса и в git не попадает — так и надо. В логах сервиса (**Logs** в дашборде) увидишь свои же slog-строки с `request_id`.

**Что нужно знать про free-план:** сервис засыпает после ~15 минут без запросов, и первый запрос после сна ждёт холодного старта где-то полминуты. Это нормально и не считается багом — просто предупреди тех, кому кинешь ссылку.

## Альтернативы

Если Render не подошёл — контракт везде один и тот же: собрать `Dockerfile`, передать `JWT_SECRET`, слушать `PORT`.

**Railway** (<https://railway.app>) — New Project → Deploy from GitHub repo. Подхватит `Dockerfile` сам. `JWT_SECRET` добавь руками в Variables, домен выдаётся по кнопке Generate Domain в настройках сервиса. Учти: у Railway пробный период — 30 дней или $5 кредитов, что кончится раньше; дальше сервис остановится.

**Fly.io** (<https://fly.io>) — `fly launch` подхватит `Dockerfile`, `fly secrets set JWT_SECRET=...`. Требует привязки карты даже на бесплатном тарифе.

## Если не завелось

| Симптом | Что происходит |
|---|---|
| Деплой «зелёный», но URL не открывается, платформа пишет про таймаут порта | Сервис слушает `:8080` жёстко и игнорирует `PORT`. См. правила выбора адреса в README. |
| Локально всё хорошо, в облаке `500` на `/` | Фронт читается с диска, а не через `embed`. Проверь `go:embed` и повтори тест из шага 1 с `cd /tmp`. |
| Сервис падает сразу после старта | Не задан `JWT_SECRET`. Так и задумано, просто добавь переменную в настройках. |
| Первый запрос висит ~30 секунд | Free-план Render проснулся из сна. Не баг. |
| В браузере CORS-ошибка, в логах бэкенда пусто | Не отвечаешь на preflight `OPTIONS`. См. `TestAcc18_CORSPreflight`. |
